# Exp135 — Log-Space Cost Regression with Variance Recovery

Exp135 is an isolated challenger to the current Exp105 Cost residual layer. It keeps the Exp61 Cost anchor, Exp105 execution factors, forward OOF evidence, project-balanced evaluation weights, and the current Exp113 Delay path. The only modelling change is that Cost residuals are learned and reconstructed in signed-log space.

The experiment must be judged against current production on both canonical windows:

- 2001–2021 training → 2022–2025 evaluation
- 2001–2022 training → 2023–2025 evaluation

Promotion requires all three constraints on a window: Cost R² improves, Cost MAE does not worsen, and Cost RMSE does not worsen. Quoted target metrics are hypotheses until the workflow completes.
