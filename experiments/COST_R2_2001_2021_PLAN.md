# Cost R² experiment — 2001–2021

Objective: improve cost-overrun R² without changing the frozen 2022–2025 holdout or production baseline.

Method:
- Keep the current canonical 2001–2021 production cost stack as the baseline.
- Diagnose rolling-OOF residuals by lifecycle stage, sector, cost scale, and large-overrun tail.
- Test leakage-safe calibration / residual correction using training-only rolling OOF predictions.
- Restrict candidate features to as-of lifecycle/trajectory values already available before completion.
- Select all calibration parameters strictly on historical rolling OOF folds.
- Evaluate once on the frozen 2022–2025 holdout.

Promotion gate:
- R² must improve over the current baseline.
- Cost MAE must not materially regress.
- No future/completion-only fields may enter features.
- No tuning on 2022–2025 outcomes.
